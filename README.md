Project : 독거노인 원터치 통화시스템

개발 동기 : 2024년 기준 65세 이상 인구 중 10.3%는 다른 가족 없이 혼자 살고있다고 합니다. 또한 65세 이상 인구 중 자살은 매달 10.5건 발생했습니다.
          그리고 그 자살의 이유는 외로움, 사회적 고립과 같은 문제였죠. 
          그래서 저희는 사회적인 외로움을 조금이라도 줄여드리기 위해 사용하기 편한 영상통화 시스템을 기획하게 되었습니다.

개발 스택 : webRTC / 실시간 영상·음성 데이터 송수신
          Express / 서버 및 라우팅 관리
          ejs / 모바일·라즈베리 UI 분리 및 디자인
          Raspberry Pi / IoT 하드웨어 플랫폼
